# Игротека Мухаммада 🦁

Бесплатные развивающие игры и раскраски для детей 4–6 лет: речь, логика, счёт, память, «Я сам», музыка, английский и 107 раскрасок с кистью, которая не выходит за линии.

**Открыть:** https://makhmudus.github.io/igroteka/

На телефоне (Chrome): ⋮ → «Добавить на главный экран» → «Установить». Работает без интернета.
